title: Code Search

---

`code_search` 是 Devo 可选的语义 retrieval tool，用于按语义、identifier 和相关位置查找代码。它以捆绑的 stdio MCP 二进制 `devo-code-search-mcp` 形式提供，**默认禁用**。

用 `devo mcp enable code_search` 或 TUI `/mcps` 启用。启用后模型看到的工具名是 `mcp__code_search__code_search`。

它不同于 shell search。Shell search 是精确文本搜索。Code search 会构建 workspace 本地索引，并用 hybrid semantic 和 sparse matching 对 chunks 排序。

## 它做什么

Code-search engine 处理：

- workspace file discovery；
- code chunking；
- dense embeddings；
- sparse BM25-style matching；
- hybrid ranking；
- related-code lookup；
- warm in-memory indexes；
- disk cache refresh。

它只读取 workspace。写入只发生在 Devo cache directory 下的 cache files。

## Operations

`code_search` 支持两个 operations：

| Operation | 用途 |
| --- | --- |
| `search` | 按自然语言或 identifier query 查找 chunks。 |
| `find_related` | 查找与源文件 + 1-indexed 行相关的 chunks。 |

Search 可按 path、content kind（`code` / `docs` / `config` / `all`）、language filters、`top_k` 限定范围。默认返回 5 条，最多 20 条。

## 本地模型

生产环境使用本地 model2vec embedding：`minishlab/potion-code-16M`，首次 embedding 时懒加载。离线环境需预先安装模型缓存（`install.sh --install-code-search-model`）。

## 何时使用

语义探索、架构问题、related-code、自然语言意图时用 code search；精确字符串 / 正则用 grep / shell search。
