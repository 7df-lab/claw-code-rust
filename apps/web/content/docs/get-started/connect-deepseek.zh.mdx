---
title: 连接 DeepSeek
description: 将 DeepSeek 官方 API 配置为 provider Connection。
---

DeepSeek 官方 API 是 Devo 很适合的第一个 Connection。建议优先使用 Anthropic 兼容路径，
这样 Devo 可以使用 provider-hosted web 能力。

官方参考：

- [DeepSeek API docs](https://api-docs.deepseek.com/)
- [Anthropic API](https://api-docs.deepseek.com/guides/anthropic_api)
- [Models and Pricing](https://api-docs.deepseek.com/quick_start/pricing)

## 创建 Connection

先在 [DeepSeek Platform](https://platform.deepseek.com/api_keys) 创建 API key，然后运行：

```bash
cd /path/to/your/repo
devo onboard
```

选择 DeepSeek provider template，确认只读 endpoint，输入 API key，选择 model 并确认。
推荐值如下：

| 设置 | 值 |
| --- | --- |
| Base URL | `https://api.deepseek.com/anthropic` |
| Wire API | `anthropic_messages` |
| Model | DeepSeek 当前支持的 model id |

API key 会保存到用户级 `auth.json`。`providers.json` 只保存 credential 引用和 Connection 的
model record。

## 手动配置

用户 Connection 使用 `<DEVO_HOME>/providers.json`，工作区覆盖项使用
`<workspace>/.devo/providers.json`：

```json
{
  "model": "deepseek/deepseek-v4-flash",
  "small_model": "deepseek/deepseek-v4-flash",
  "provider": {
    "deepseek": {
      "name": "DeepSeek Anthropic",
      "base_url": "https://api.deepseek.com/anthropic",
      "credential": "deepseek_api_key",
      "wire_api": "anthropic_messages",
      "web_search": {"mode": "provider"},
      "web_fetch": {"mode": "provider"},
      "models": {
        "deepseek-v4-pro": {
          "name": "DeepSeek V4 Pro",
          "default_reasoning_effort": "high"
        },
        "deepseek-v4-flash": {
          "name": "DeepSeek V4 Flash",
          "default_reasoning_effort": "high"
        }
      }
    }
  }
}
```

密钥单独保存到 `<DEVO_HOME>/auth.json`：

```json
{
  "version": 1,
  "credentials": {
    "deepseek_api_key": {
      "kind": "api_key",
      "value": "sk-your-deepseek-api-key"
    }
  }
}
```

Provider map key（`deepseek`）和嵌套 model map key 组成稳定的 `provider/model` identity。
不再需要单独的 binding、slug、request-model 或 description 字段。

## OpenAI 兼容替代路径

如果明确需要 DeepSeek 的 OpenAI Chat Completions 格式，可以创建单独的 Connection：

```json
{
  "model": "deepseek-openai/deepseek-v4-flash",
  "provider": {
    "deepseek-openai": {
      "name": "DeepSeek OpenAI Compatible",
      "base_url": "https://api.deepseek.com",
      "credential": "deepseek_api_key",
      "wire_api": "openai_chat_completions",
      "models": {
        "deepseek-v4-flash": {"name": "DeepSeek V4 Flash"}
      }
    }
  }
}
```

## 验证

运行：

```bash
devo doctor
devo
```

如果失败，检查 credential id 是否匹配 `auth.json`、base URL 是否匹配 wire API，以及嵌套的
model id 是否仍受 DeepSeek 支持。需要更换 endpoint 或 credential 时，从 `devo onboard` 断开
并重新连接该 Connection。
