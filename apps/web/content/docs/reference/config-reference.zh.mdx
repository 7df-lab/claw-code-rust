本页列出主要 config files 和 fields。引导式配置请先读[配置基础](../configuration/config-basics)、[提供商配置](../configuration/provider-setup) 和[Provider 与 Model 配置](../configuration/model-bindings)。

## 文件

| File | Purpose |
| --- | --- |
| `<DEVO_HOME>/config.toml` | User-level Devo config。 |
| `<DEVO_HOME>/providers.json` | User-level provider connections、model directory 和 active model。 |
| `<DEVO_HOME>/auth.json` | User-level secrets 和 credentials。 |
| `<workspace>/.devo/config.toml` | Workspace-level config overlay。 |
| `<workspace>/.devo/providers.json` | Workspace provider/model overlay。 |

默认 `DEVO_HOME` 路径：

| Platform | Default |
| --- | --- |
| macOS/Linux | `~/.devo` |
| Windows | `C:/Users/your-username/.devo` |

如果设置了 `DEVO_HOME`，它必须指向已经存在的目录。

## 优先级

Effective config 按以下顺序解析，优先级从高到低：

1. command-line startup arguments；
2. `<workspace>/.devo/providers.json`（provider/model 字段）；
3. `<workspace>/.devo/config.toml`（application 字段）；
4. `<DEVO_HOME>/providers.json`（provider/model 字段）；
5. `<DEVO_HOME>/config.toml`（application 字段）；
6. built-in defaults 和 git 跟踪的 `crates/core/providers.json`。

Provider API key 存在 user-scoped `auth.json`；`providers.json` 只存
`provider.<id>.credential` 引用。包含真实密钥的文件都不应提交到仓库。

## providers.json

`<DEVO_HOME>/providers.json` 和 `<workspace>/.devo/providers.json` 保存 provider
连接、模型目录和选择。`model` 是普通 turn 的默认主模型，`small_model` 是可选的
轻量后台模型（例如会话标题生成）；未设置或无效时先自动选择同 provider 的轻量模型，
再回退到 `model`。provider id 与嵌套
model id 共同组成唯一身份 `provider/model`，不需要额外的 binding id。

## Top-Level Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `summary_model` | enum | 选择用于 context summaries 的模型。 |
| `server` | table | Server runtime defaults。 |
| `logging` | table | Diagnostic logging behavior。 |
| `skills` | table | Skill discovery roots 和 behavior。 |
| `experimental` | table | Experimental feature gates。 |
| `mcp_oauth_credentials_store` | `auto`, `keyring`, `file` | MCP OAuth credentials 的存储 backend。 |
| `mcp` | table | MCP server discovery 和 runtime config。 |
| `tools` | table | Tool-specific runtime config。 |
| `hooks` | table | External lifecycle hooks。 |
| `provider_http` | table | Shared provider HTTP transport settings。 |
| `updates` | table | Startup update-check defaults。 |
| `project_root_markers` | string array | 用于发现 instruction project root 的 markers。默认 `.git`。 |
| `projects` | table | 按 project key 记住的 user-level settings。 |

应用级字段位于 `config.toml`；provider/model 字段位于 `providers.json`：

| Field | Meaning |
| --- | --- |
| `model` | 默认主模型，格式为 `provider/model`。 |
| `small_model` | 标题生成等轻量后台任务使用的可选模型；缺省时自动选择轻量模型，再回退到 `model`。 |
| `reasoning_effort` | 当前 reasoning effort 选择。 |
| `provider.<id>` | Connection 与其模型目录。 |
| `provider.<id>.models.<model-id>` | 模型记录，map key 就是 provider-facing model id。 |

旧 TOML 的 provider/model 字段仅作为启动时一次性迁移输入读取；新的配置和运行时
解析不再使用 bindings。

## `[provider_http]`

| Field | Type | Meaning |
| --- | --- | --- |
| `proxy_url` | string | Provider requests、local web fetch/search 以及 code search 模型下载使用的可选代理 URL。支持 `http://`、`https://`、`socks5://` 和 `socks5h://`。 |
| `no_proxy` | string | 可选 comma-separated host bypass list，例如 `localhost,127.0.0.1,::1`。 |

Desktop Server network proxy settings 只在 Desktop-managed runtime process 内
override 这些值，不会修改 `config.toml`。

## `[server]`

| Field | Type | Meaning |
| --- | --- | --- |
| `listen` | string array | Server listen endpoints。 |
| `max_connections` | integer | 最大 concurrent client connections。默认 `32`。 |
| `event_buffer_size` | integer | 每个 connection 的 event buffer capacity。默认 `1024`。 |
| `idle_session_timeout_secs` | integer | Idle session timeout 秒数。默认 `1800`。 |
| `persist_ephemeral_sessions` | bool | 是否持久化 ephemeral sessions。默认 `false`。 |

### `[server.auth]`

| Field | Type | Meaning |
| --- | --- | --- |
| `enabled` | bool | 非 initialization server methods 是否需要 server authentication。默认 `false`。 |
| `method_id` | string | Initialization 时 advertised 的 server authentication method id。默认 `agent-login`。 |
| `name` | string | 用户可读 authentication method name。默认 `Agent login`。 |
| `description` | string | 可选 authentication method description。 |
| `logout` | bool | Auth enabled 时是否 advertise 并支持 ACP `logout`。默认 `true`。 |

启用后，auth state 按 connection 隔离，并同时 gate ACP methods 和 legacy
Devo server methods。

## `providers.json` Provider 与 Model

| Field | Type | Meaning |
| --- | --- | --- |
| `name` | string | 用户可读的 provider name。 |
| `enabled` | bool | Provider 是否可用。默认 `true`。 |
| `base_url` | string | Provider endpoint。 |
| `credential` | string | `auth.json` 中的 credential id。 |
| `headers` | JSON object string | Provider requests 的 extra HTTP headers。 |
| `wire_api` | string | 该 provider 默认使用的 wire API。 |
| `options`、`request` | JSON object | 任意 adapter 选项和 provider 请求默认值。 |
| `models` | object | 按 provider-facing model id 存储的模型。 |
| `web_search`、`web_fetch` | JSON object | Provider-level capability override。 |

支持的 wire API 值：

- `anthropic_messages`
- `openai_chat_completions`
- `openai_responses`

Provider 响应没有应用层总超时。本地模型可以按需要花费时间加载或生成输出，
用户可以随时取消请求；连接建立仍保留内部期限。

Model record 的字段、variants、reasoning、任意 `request/options/headers` 和动态发现格式，
详见[Provider 与 Model 配置](../configuration/model-bindings)。

## `[tools.web_search]`

| Field | Type | Meaning |
| --- | --- | --- |
| `mode` | `disabled`, `provider`, `local` | Effective web search mode。默认 `provider`。 |
| `local_provider` | string | 选中的 local provider id。当存在多个 local providers 时必需。 |
| `local_providers` | table | Local search provider definitions。 |

Local provider fields：

| Field | Type | Meaning |
| --- | --- | --- |
| `kind` | `exa`, `tavily` | Search service kind。 |
| `credential` | string | `auth.json` 中的 credential id。 |
| `base_url` | string | 可选 service endpoint override。 |
| `max_results` | integer | 可选 result limit。 |

## `[tools.web_fetch]`

| Field | Type | Meaning |
| --- | --- | --- |
| `mode` | `disabled`, `provider`, `local` | Effective web fetch mode。默认 `local`。 |

## `[research]`

| Field | Type | Meaning |
| --- | --- | --- |
| `max_researcher_iterations` | integer | 传给 researcher prompt 的 search/fetch iteration guidance。默认 `5`。 |
| `fetch_summary_threshold_chars` | integer | 本地 `webfetch` 文本超过该长度时，research 会先汇总 fetched page。默认 `24000`。 |
| `max_summary_chars` | integer | 超大 webpage summaries 的目标上限。默认 `8000`。 |

## `auth.json`

`auth.json` 存储 user-scoped credentials：

```json
{
  "version": 1,
  "credentials": {
    "deepseek_api_key": {
      "kind": "api_key",
      "value": "sk-your-key"
    }
  }
}
```

Credential fields：

| Field | Type | Meaning |
| --- | --- | --- |
| `version` | integer | Credential file schema version。当前值为 `1`。 |
| `credentials.<id>.kind` | `api_key` | Credential kind。 |
| `credentials.<id>.value` | string | Secret value。 |

不要提交 `auth.json`。

## Update Checks

默认 update config 启用 startup checks，最小间隔 24 小时：

```toml
[updates]
enabled = true
check_on_startup = true
check_interval_hours = 24
```

需要完全离线运行的环境应禁用 startup checks。
